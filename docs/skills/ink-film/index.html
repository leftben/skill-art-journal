影像與影片 · 單一 Skill

把自己的文字畫成有墨線、紙紋與聲音的短片

從文案、分鏡與風格定稿開始，以程式繪出每格畫面，再輸出網頁和影片。

Ink Film3 GitHub 星收錄 2026.11.18資料核對 2026.11.24
它怎麼幫忙可以這樣開口開始之前作者與來源

如果你希望書店故事、短詩或品牌文案變成一支手繪感短片，Ink Film 提供一套製作流程。它讓 AI 助手用 JavaScript 在 Canvas 上畫每格影像，以抖動墨線、雕刻排線、紙紋和逐字出現的文字，組成有節奏的動畫，不靠現成影片拼接。

它怎麼幫忙

先確認自有文字、片長、比例、聲音與視覺方向，再共同討論解讀及分鏡。完成一個代表畫面並確認畫風後，才逐段繪製動畫，檢查接續、字幕與輸出。預設有雕刻宇宙、藍曬工程圖、孔版套色，以及依品牌色和字體調整的方向。

可以這樣開口

這是一個可依需求修改的委託範例。

用自己寫的書店介紹，做一支 30 秒孔版套色短片：書頁展開、墨線形成書架，最後出現店名。先確認分鏡及一張風格畫面，再交付直式 Reels 與橫式網站版。這是本站需求範例，未執行製作。

適合什麼工作

適合想將文字轉成插畫動畫、願意逐段檢查構圖和動作的插畫師、動態設計者與小型品牌團隊。

開始之前

準備工具
Google Chrome、Node.js 20+、ffmpeg（含 libx264），每支影片另用 playwright-core 驅動 Chrome；需能讀寫程式並執行工具的 AI 助手。腳手架與建置步驟使用 Bash，相容 shell 環境需自行準備，Windows 未經本站實測。
使用成本
程式採 MIT，Canvas 繪圖路線沒有必要的付費生圖 API；AI 助手訂閱或模型用量、電腦與製作時間另計。品牌素材、字體與文字應具有使用權。
交付內容
可開啟的完整網頁、一般與分享版 MP4、無聲 MP4、WAV 音軌、海報；有腳本台詞時另附 SRT 字幕，支援 1:1、9:16 與 16:9。
