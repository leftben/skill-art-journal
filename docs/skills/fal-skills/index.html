fal.ai 的模型種類很多，真正困難的往往是如何選擇、如何串接。這套 Skills 把角色設計、攝影語言、故事與遊戲素材等經驗整理給 agent 使用。

它怎麼幫忙

主要執行路徑是 genmedia CLI。AI 先找模型端點、閱讀輸入規格，再執行並查詢狀態。character-design 關注身分參考，fal-gamedev 關注角色、精靈圖與背景。

可以這樣開口

這是一個可依需求修改的委託範例。

以這張原創角色設定為身分參考，規劃三個鏡頭的短片。先列出模型與預估用量，再生成關鍵畫面，核對角色一致性。

適合什麼工作

適合已使用 fal.ai，想讓生成流程更有條理的人。
