先看概念，再選方向；用小尺寸、單色與反白檢查標誌是否成立。

品牌標誌不只是一張漂亮圖。這個 Skill 把訪談、概念發想、SVG 幾何繪製與實際尺寸測試放在同一個流程裡。

它怎麼幫忙

它先研究需求與類別慣例，提出概念並做三個 SVG 方向，檢查縮小、單色及反白等情境。到概念檢視點會停下來，讓你選擇後才延伸完整品牌套件。

可以這樣開口

這是一個可依需求修改的委託範例。

為一家專做木作修復的工作室提出三個標誌方向。先用黑白 SVG 呈現，檢查 16px 圖示與招牌應用，等我選方向後再做品牌套件。

適合什麼工作

適合品牌初期方向探索、識別設計與需要可編輯向量交付的人。

開始之前

準備工具
支援 Agent Skills 並能看圖的 agent、Python 工具；部分輸出依專案設定。
使用成本
主要依 agent 方案計算；參考庫用來研究構成，不代表可直接挪用既有標誌。
交付內容
SVG 標誌、概念比較圖、品牌規範及圖示套件
先留意
原作者範例中的品牌是虛構 brief。實際品牌仍須自行確認原創性與適用性。
