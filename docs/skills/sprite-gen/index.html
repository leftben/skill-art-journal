像素與遊戲 · 單一 Skill 與 CLI

把一張角色圖，整理成遊戲能播放的透明動畫

依動作分批生成、去背與挑選影格，再交付有座標和時間資料的遊戲圖集；也能從影片擷取透明循環。

它怎麼幫忙可以這樣開口開始之前作者與來源

角色圖畫好了，真正放進遊戲前，還需要待機、走路、跳躍和攻擊的連續影格。Sprite Gen 把這些工作串成流程：先按動作生成，再清掉背景、分離姿勢、對齊角色，最後交付遊戲能讀的透明圖集與逐格資料。

它怎麼幫忙

有兩條主要路線。圖集路線把同一角色的動作分批製作，再去背、抽取影格，透過可選的網頁挑選介面剔除不合格姿勢、微調位置與預覽循環。影片路線讓靜態角色先經影片模型產生動作，再找循環週期、轉成透明影格與 GIF／WebP／長條圖。也提供換色、呼吸動態、背景重複貼圖和投影工具。配圖是作者公開的聖騎士攻擊示例，並非本站執行結果。

10 月 30 日核對到 3.9.0：影片切段現在預設偵測連續重複姿勢，使用 RIFE 補上中間影格並重新檢查，報告列出補前與補後的姿勢數／總格數。也可指定較高輸出幀率；沒有 RIFE 時會警告並保留原幀率。像素呼吸新增圓胸與手臂橫移控制，可以用遮罩固定部位，讓手持物整塊跟著移動。

三步驟看懂這個技能

可以這樣開口

這是一個可依需求修改的委託範例。

用我有權使用的側面小騎士原圖，規劃待機、走路與攻擊三種狀態。先說明生成供應商和費用，固定角色大小、朝右方向與腳底基準；逐狀態預覽，確認臉和武器沒有變形，再交付透明圖集、每格座標和播放時間，另附白底去背檢查與循環 GIF。 若影片走路中途停格，先報告重複姿勢數，預覽補間後腳底是否滑動、武器是否出現殘影；刻意保留的低格率動畫則關閉自動補間。

適合什麼工作

適合獨立遊戲開發者、需要快速做出可玩的角色原型的人，以及手上已有角色原圖、願意逐段檢視動作的美術與工程搭檔。已有圖集也可只使用切圖、去背、換色與匯出工具。

開始之前

準備工具
CPython 3.11+ 與專用虛擬環境、Pillow、NumPy；生成需支援的 Codex／Grok 工具與自己的登入或 API 憑證。影片流程另需 ffmpeg、img2webp；走跑修補與多方向週期對齊使用 RIFE，缺少時會警告並保留原拍攝切法。部分進階臉部流程需要 Node。作者 CI 僅跑 Python 3.14，並非每個版本與作業系統都已測試。 新版自動填補停格與提高輸出幀率也需要 RIFE；可用 --fill-held off 保留原切法。
使用成本
專案為 Apache-2.0；角色生圖與影片依供應商或既有訂閱額度計費。現有素材的切圖、去背與 RIFE 補間可在本機處理，仍有 AI 助手、運算與人工檢視成本。4.0 起已移除 sound 聲音功能。
交付內容
透明 sprite-sheet-alpha.png、含影格座標與播放資料的 manifest.json、逐動作透明 GIF／WebP／長條圖、檢查接觸表；可選 Aseprite 相容 JSON 供 Phaser／Flame 等引擎讀取
先留意
2026-10-29 首次收錄，2026-11-03 依 3.15.0 及 main 的未發布移除項目實質更新。補幀可能保留停格或拒絕不合格中間影格，不能保證每格補間成功。v4.0.0 仍是未發布變更標題；main 移除的 game-pack 改由 compose-atlas 與 export-aseprite 交付圖集，後者是相容 JSON，不是 .aseprite 原檔。作者配圖是既有成果，不是新版模型對照測試。

最近的觀察

2026-11-03：核對至 3.15.0 與其後 main。補幀預設改為 RIFE v4.25，舊 v4.6 可指定保留；需要重新下載模型，官方文件列出約 830 MB 下載、保留約 45 MB。不同模型可能保留更多或更少姿勢，不是全面品質保證。main 已移除聲音、game-pack、ui-kit 與雙軸背景貼圖，變更表仍標為未發布 v4.0.0，不能說正式 4.0 已推出。 2026-11-07：已到 4.1.0。循環動畫會檢查尾端接回開頭的重複畫面，必要時以本機 RIFE 補中間影格，並記錄刻意停格與精確播放速率；inspect-holds 可找出未列明的停格。例如角色每走一圈腳會停一下，可先核對重複格而非重新付費生成整段。4.1 的道具遮罩板會逐格追蹤並移除，減少鏡頭移動後留下桃紅色板子的問題；遮住或移動過遠仍可能找不到，接觸主體也需人工查看。這些後製不新增模型呼叫，但需要本機處理與 RIFE 環境。4.0 已移除 sound、game-pack、ui-kit 和雙軸背景拼接功能，舊檔仍在；本工具重心回到精靈素材。 2026-11-08：4.2 會在補格後的循環旁保留未補格來源 cycle.source，讓多方向動畫即使移到別處、沒有原始影片影格，仍可對齊；搬移時必須一併帶走來源資料夾。4.3 的道具遮罩移除會一起處理模型畫出的側面、頂面與邊線，並警告遮罩側面碰到主體的影格。例如角色握住去背用色板，能減少去掉正面後殘留側邊；接觸主體仍需逐格看。這些修補是本機後製，不增加模型呼叫，沿用 ffmpeg、RIFE 等工具與運算成本。
