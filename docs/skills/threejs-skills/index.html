3D 與材質 · Skill 合集

讓你的 3D 模型，在網頁上動起來

用十三項技能處理場景、材質、打光、動畫與資產壓縮，把既有模型帶上網頁。

你已有一個鞋子模型，接下來想讓觀眾用滑鼠旋轉、看清材質，還要在手機上順暢載入。Three.js Skills 提供的是這段網頁實作的知識與範例。

它怎麼幫忙

合集從相機與場景開始，延伸到 PBR 材質、燈光、shader、互動、骨架與 morph 動畫、React Three Fiber 以及 glTF 資產管線。資產流程會先檢查模型，再壓縮幾何與貼圖，配合正確的解碼器。README 以 Three.js r186 為目標版本，這是作者文件的驗證範圍。

可以這樣開口

這是一個可依需求修改的委託範例。

把我已有的鞋子 GLB 做成網頁商品展示：可拖曳旋轉、調整打光並切換材質。先確認模型與貼圖尺寸，再壓縮載入檔案，檢查手機操作與視窗縮放。

適合什麼工作

適合能維護 JavaScript 的網頁設計師、互動開發者，以及想在作品集展示模型的 3D 美術。它協助完成展示與互動，不會憑空生成精緻模型。

開始之前

準備工具
瀏覽器、Three.js 與能寫程式的 AI agent；使用 npm、打包工具或 glTF-Transform 資產處理時需要 Node.js。模型與材質素材由你準備，實際圖形功能依瀏覽器能力而定。
使用成本
技能採 MIT，沒有必需的付費生圖服務。AI agent 用量、模型素材和網站託管依各自方案計算；本誌沒有執行作者的版本驗證。
交付內容
網頁 3D 場景、互動與動畫程式、經整理壓縮的 glTF／GLB 資產
