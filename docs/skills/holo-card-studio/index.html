3D 與材質 · 單一 Skill

讓角色卡，隨角度閃起來

把角色、背景、線稿和文字拆成圖層，做成 Blender 工程與互動網頁。

Holo Card Studio1,969 GitHub 星收錄 2026.10.20資料核對 2026.10.21
它怎麼幫忙可以這樣開口開始之前作者與來源

Holo Card Studio 把卡面當成可以操作的材質作品。角色和背景在空間上略微分開，再加入隨角度變化的全息效果，形成可旋轉、翻面的卡片。

它怎麼幫忙

全息路線使用背景、主體、線稿與文字四層圖，建立 Blender 場景，再用 Three.js 做瀏覽器查看器。專案也有雙圖光柵路線，讓兩張完整卡面隨角度切換。

可以這樣開口

這是一個可依需求修改的委託範例。

用這張原創角色圖做一張金色邊框的收藏卡，保留角色臉型與構圖，分開文字層，交付可調材質的 Blender 工程和手機可看的網頁。

適合什麼工作

適合遊戲角色卡、紀念卡、材質研究與互動展示。

開始之前

準備工具
Python 3＋Pillow、Node.js＋npm；流程可取得官方 Blender 便攜版，也能使用現有 Blender。
使用成本
圖層素材若需生圖，依工具計費；執行和渲染需要本機資源。
交付內容
.blend、分層素材、互動網頁與渲染圖
先留意
網頁與 Blender 離線燈光不同，顏色和輝光可能有差異；授權請直接查看專案。
