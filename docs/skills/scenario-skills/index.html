Scenario Skills 是一整套創意工作流程，讓 agent 知道何時選哪種生成方式、如何使用參考，以及如何維持角色或品牌的一致性。

它怎麼幫忙

可從圖像、遊戲資產、精靈動畫、材質與 3D 等任務挑選技能。Scenario 生成路線透過 MCP 連線；另外的 DCC 專家工具則驅動本機 Blender、Maya 等軟體，需求不同。

可以這樣開口

這是一個可依需求修改的委託範例。

替一款森林橫向遊戲規劃主角、三種敵人與背景素材，先鎖定畫風，再分批生成並檢查角色比例與透明背景。

適合什麼工作

適合需要一系列遊戲素材或跨媒體製作流程的人。

先留意

最近的觀察

2026-10-27：0.60.0 新增影片動作捕捉 Skill，可把手機拍攝的人體動作轉成角色動畫，或只取標準骨架上的動作再重定向。既有角色骨架要保留時，應走動作檔與骨骼對應流程；自動綁定路線不會直接沿用原骨架。例如將八秒舞蹈交給遊戲角色，先檢查全身與腳掌是否入鏡，再檢查朝向、落腳及循環接點。另補上綠／藍幕去背：透明成品選 WebM 或 ProRes 4444 MOV，MP4 只能合成實色背景。純文字 3D 路線也已寫入指引，可直接描述寶箱並命名蓋子、箱體和鎖；圖片轉 3D 仍有較多可選模型。Blender 匯出新增實際尺寸與落地樞紐、金屬度／粗糙度貼圖檢查，以及減面時避免 UV 接縫裂開。生成、動捕及影片處理按模型與片長計費，需 Scenario MCP 與帳號；本次只核實文件與差異，未執行生成。
