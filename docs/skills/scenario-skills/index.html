把遊戲美術需求，接成生成流程

從角色、精靈圖與材質，到分鏡、影片與 3D，依任務選擇工作方法。

它怎麼幫忙可以這樣開口開始之前作者與來源

Scenario Skills 是一整套創意工作流程，讓 agent 知道何時選哪種生成方式、如何使用參考，以及如何維持角色或品牌的一致性。

它怎麼幫忙

可從圖像、遊戲資產、精靈動畫、材質與 3D 等任務挑選技能。Scenario 生成路線透過 MCP 連線；另外的 DCC 專家工具則驅動本機 Blender、Maya 等軟體，需求不同。

可以這樣開口

這是一個可依需求修改的委託範例。

替一款森林橫向遊戲規劃主角、三種敵人與背景素材，先鎖定畫風，再分批生成並檢查角色比例與透明背景。

適合什麼工作

適合需要一系列遊戲素材或跨媒體製作流程的人。

開始之前

準備工具
Scenario 路線需帳號與 MCP 連線；DCC 專家工具依軟體家族另行設定。

交付內容
依子技能交付圖片、動畫、材質、影片或 3D 資產
先留意
這是大型合集，建議只選眼前工作需要的子技能。

最近的觀察

2026-10-27：0.60.0 新增影片動作捕捉 Skill，可把手機拍攝的人體動作轉成角色動畫，或只取標準骨架上的動作再重定向。既有角色骨架要保留時，應走動作檔與骨骼對應流程；自動綁定路線不會直接沿用原骨架。例如將八秒舞蹈交給遊戲角色，先檢查全身與腳掌是否入鏡，再檢查朝向、落腳及循環接點。另補上綠／藍幕去背：透明成品選 WebM 或 ProRes 4444 MOV，MP4 只能合成實色背景。純文字 3D 路線也已寫入指引，可直接描述寶箱並命名蓋子、箱體和鎖；圖片轉 3D 仍有較多可選模型。Blender 匯出新增實際尺寸與落地樞紐、金屬度／粗糙度貼圖檢查，以及減面時避免 UV 接縫裂開。生成、動捕及影片處理按模型與片長計費，需 Scenario MCP 與帳號；本次只核實文件與差異，未執行生成。 2026-11-04：Blender 預演新增自行車和騎乘配置，可依騎士身高縮放車架，讓有關節的人偶雙手握把、雙腳隨踏板踩動。例如先排出兩位騎士沿街前進的鏡頭，再決定是否送往生成影片。膠囊替身只會坐著前傾，不能說已具完整踩踏；作者在 Blender 5.2.1 檢查幾何與接觸，但不同影片模型是否能保住踩踏動作仍未測試。沿用既有生成與動捕能力；本機預演需 Blender，後續 Scenario 生成另外計費。 2026-11-07：新增 playable ads，可由自己的遊戲錄影、截圖與現有美術，重做只有一個主要操作的 HTML5 試玩廣告，例如讓玩家拖一次合成物件後再顯示安裝按鈕。包含提示手勢、靜音、結尾卡與九種廣告網路封裝；作者的多網路自動測試多使用模擬容器，只有文件列出的 Meta、AppLovin 和 Google App Campaigns 工具有另行核對，不能當成九平台都已正式審核。需要 Python 3.12+、影像套件、Playwright/Chromium 與 ffmpeg；缺少素材時才走 Scenario 付費生成。動態音樂影片另新增分段動量檢查，其預設門檻只以合成測試校準，尚非實片品質保證。整體文件另明確要求 Node 22.18+，Windows 符號連結需按環境設定。 2026-11-08：新增手機遊戲 UA 影片廣告流程，把遊戲截圖或錄影拆成盤面、操作動作、計分 HUD、手勢、音效與結尾卡，逐鏡檢查玩法邏輯。例如把自己的合成遊戲素材做成 15 秒直式廣告，數字與按鈕以獨立圖層合成，避免讓影片模型亂畫；這是影片廣告，與昨日的可操作 HTML5 試玩廣告不同。需要 Scenario MCP、服務點數、Python／影片合成工具與人工檢查；規格檢查不等於廣告平台核准。音樂影片另加入 4K 主檔與動態模糊的製作指引，既有影片修改也擴充重剪流程。3D 參考圖改為優先純背景原圖，避免光滑物體的環境反光被烘進材質；Blender 低於 5.2 的網頁匯出停用 meshopt，以免匯出參數不相容。未執行或付費驗證生成品質。 2026-11-09：0.61.0 新增漫畫製作與文字動態宣傳片流程。漫畫先定故事、畫風、角色設定與分鏡，再逐頁檢查人物連續性、對白可讀性，最後組合成 PDF；例如把工作室的新人訓練做成八頁漫畫。動態宣傳片則用程式把大字、3D 字、產品圖與結尾卡排在音樂拍點上，可輸出 1080p／4K；例如做一段 24 秒遊戲預告，文字保留精確拼寫。另修正像素動畫全片共用調色盤、靜止片段的循環評分與試玩廣告達標結束流程；Tripo 的 PBR 預設須依具體模型核對，不再一概當作開啟。漫畫與生成素材需 Scenario MCP 及付費點數；影片編排另需 Node 20+、Python 3.12／uv、ffmpeg 和 Chrome。檢查通過不代表畫面品質保證，本站未呼叫生成服務。 2026-11-12：0.62.0 補上 MiniMax H3 影片 LoRA 訓練指引，可用圖片、短片，或短片與參考素材配對來學習特定風格。例如讓同一系列遊戲角色的宣傳短片維持一致外觀；純圖片的 int8 路線不會從素材學到動作。另可從一段遊戲概念或類型名稱開始做互動廣告，先交代手指怎麼操作、最精彩的時刻與結束方式，再準備兩張概念畫面；沒有商店連結的成品只作預覽，不能當成已上架遊戲廣告。適合已有素材與授權、需要系列影片或廣告概念的團隊。需 Scenario 帳號與 MCP；互動廣告另需 Python 3.12、Pillow/numpy/scipy/fontTools/brotli、Playwright Chromium 和 ffmpeg。推薦模型、生成與訓練可能消耗 CU，訓練需在素材與配對完成後重新報價，啟動會收費且停止不退費。影片模型另受 MiniMax H3 授權約束：輸出不可拿去訓練其他 AI 模型，真人肖像需符合授權及同意條件。這是技能流程擴充，本站未訓練模型或測試廣告平台。
