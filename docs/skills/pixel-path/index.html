像素與遊戲 · 單一 Skill

把走過的路，變成像素街景

輸入兩個地點，用地圖與地域素材，組成可在瀏覽器穿梭的像素公路。

它怎麼幫忙可以這樣開口開始之前作者與來源

一段旅途也能變成會移動的像素場景。Pixel Path 從真實路線出發，讀取建築、地形與地標，再用符合地域風格的圖片組成沿路風景。

它怎麼幫忙

先計算路線與素材估價，可用免費佔位圖確認構成，再決定是否生成正式建築和樹木。輸出為可自行託管的 HTML 場景，能加速、倒退與暫停。它使用類街機的透視投影；地標是圖片，並不是可自由轉看的城市 3D 模型。

可以這樣開口

這是一個可依需求修改的委託範例。

先用免費佔位圖，把京都車站到金閣寺做成像素公路場景。確認沿路節奏、地標與地圖署名，提供正式圖片估價，等我確認預算後再生成素材。

適合什麼工作

適合旅行回顧、lo-fi 背景、道路遊戲原型與影片開場。

開始之前

準備工具
Node 18+、可連線地圖服務；完整截圖檢查需 Node 20+、Playwright 與 Chromium。正式圖片需 RetroDiffusion 帳號、API key 與餘額。
使用成本
佔位圖可免費試構成。作者京都範例使用四張圖、估計 US$0.72；這是範例費用，正式生成以即時報價為準，並預留重抽預算。
交付內容
可自行託管的像素公路 HTML 場景與路線資料
先留意
今天首次收錄的小眾工具。地圖覆蓋影響成果；公開資料需保留 OSM 署名與 ODbL 條件，圖像另有條款。本站使用功能示意圖，原作街景可從來源連結查看。
