文章談「做減法」，配圖卻只剩幾個抽象圖示？橙線插畫會先找出內容的矛盾，再用極小人物與巨大物件的動作，把一個觀點畫成一張留白插圖。黑色細線、純白背景和一點暖橙色，讓同一系列的文章或演講維持一致。

它怎麼幫忙

先提煉句子要說的意思，設計看得懂的動作場景，安排橙色落在最重要的位置，再把候選圖交給人挑選。多張圖預設沿用胸口橙點的小橙角色；需要其他人物時先選角色設定。投影片路線會先確認大綱、逐頁生圖與選圖，再組成有導覽和進度條的 HTML。

可以這樣開口

這是一個可依需求修改的委託範例。

為「功能太多會讓人找不到重點」畫一個小人物，正把整面巨大的按鈕牆擦到只剩一個橙色按鈕；再用同一角色為另外三個產品原則配圖。這是本站需求範例，未執行生成。

適合什麼工作

適合文章作者、產品設計者、講師，以及需要一套一致概念插圖的內容編輯。
