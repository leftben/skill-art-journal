3D 與材質 · 單一 Skill

用 Blender 做出黏土偶一格一格動起來的短片

先排故事節拍，再用程式搭景、做黏土偶，檢查關鍵格後渲染成影片。

它怎麼幫忙可以這樣開口開始之前作者與來源

想做一支企鵝走出冰屋、接住雪花的小短片，這個 Skill 把做法整理成可改寫的 Blender 場景與製作流程。它建立真正的 3D 微縮場景，用不規則黏土表面、淺景深和微小抖動，營造手作停格感。

它怎麼幫忙

先以格數寫分鏡與動作節拍，再改寫企鵝或桌面黏土球範例。用簡化幾何組角色、父子樞紐做動作，表情用替換零件；每秒十二個不同姿態，輸出二十四格 MP4。先看四至六張代表畫面，確認曝光、接地與構圖，再做整段 Cycles 渲染。

可以這樣開口

這是一個可依需求修改的委託範例。

做一支二十秒工作室片頭：黏土小球醒來、長出星芒、跳上書本，最後定格在自有標誌旁。先交關鍵格確認，再輸出影片。這是本站需求範例，未實際渲染。

適合什麼工作

適合會調整 Blender 場景、願意檢查動作與等待渲染的動畫師、遊戲美術和小型品牌。

開始之前

準備工具
Blender 4.2+、FFmpeg 與能執行 Python 的 AI 助手；作者稱測試於 Blender 5.2。GPU 可加速，CPU 可降低解析度與採樣。現成執行和編碼腳本採 Bash；Windows 需相容 shell 與路徑調整，本站未測。
使用成本
MIT；本機建模渲染不必使用付費生圖 API。AI 助手額度、電腦與渲染時間另計。作者以 Apple M4 Pro 製作二十秒 1600×900 約二十五至三十分鐘，僅為作者參考值，不代表你的硬體速度。
交付內容
Blender Python 場景、PNG 序列、接觸表與 MP4；可選影片播放器頁面。
