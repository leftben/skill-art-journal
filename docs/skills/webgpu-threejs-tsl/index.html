3D 與材質 · 單一 Skill

讓網頁裡的材質與粒子，動起來

把 Three.js 場景、TSL 材質、GPU 粒子與後製串起來，協助製作互動 3D 視覺。

WebGPU Three.js TSL Skill1,262 GitHub 星收錄 2026.10.24資料核對 2026.10.29
它怎麼幫忙可以這樣開口開始之前作者與來源

網站需要可以點擊、旋轉和改變的視覺時，一張完成的圖片通常不夠。這份技能提供 Three.js 與 WebGPU 的製作知識，讓 agent 在同一個場景裡安排材質、粒子和互動。

它怎麼幫忙

真正的 SKILL.md 串起七份主題文件、五個程式範例、兩個模板與快速參考。TSL 用 JavaScript 形式組織著色邏輯；內容從場景初始化、節點材質、GPU 計算到發光與景深，也提醒裝置限制和顯示卡失效後的恢復。作者粒子範例包含位置、速度、重力、反彈與點擊受力。

可以這樣開口

這是一個可依需求修改的委託範例。

替展覽網站做可互動粒子主視覺：點擊後粒子向外散開，再落回地面。先做小規模原型，將材質、滑鼠互動與後製分開控制，並在目標裝置確認速度和 WebGPU 可用性。

適合什麼工作

適合已接觸 JavaScript 或 Three.js 的創意前端、技術美術與互動設計師，尤其是要把 3D 展示整合進網站的人。

準備工具
AI 編碼 agent、JavaScript／Three.js 專案環境，以及支援所需功能的瀏覽器和 GPU。作者提供 Claude Code Skill 與 Cursor 規則兩條路徑；文件標示對齊 Three.js r183+，導入時需固定專案版本。

交付內容
