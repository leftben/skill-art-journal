網頁與介面 · 單一 Skill

讓 AI 做網頁時，有美術方向

從版面、字體、圖片到瀏覽器檢查，把網站做成有明確方向的作品。

Taste Skill99,358 GitHub 星資料核對 2026.10.20
它怎麼幫忙可以這樣開口開始之前作者與來源

Taste Skill 像是替寫網頁的 AI 加一位美術指導。它先讀懂主題，再選擇視覺方向、安排字體與版面，搭配真正的圖片，把想法落實成可使用的網頁。

它怎麼幫忙

它會在實際瀏覽器檢查不同寬度的畫面，再看截圖修正問題。網站和儀表板各有自己的規則；儀表板重視清楚的資料與操作，宣傳頁重視主題、內容與構圖。

可以這樣開口

這是一個可依需求修改的委託範例。

替陶藝工作室做作品網站，以窯燒過程與器物照片建立方向。桌機、平板、手機都要檢查，並修正最明顯的三個問題。

適合什麼工作

適合作品集、品牌官網、產品頁與希望改善 AI 網頁視覺品質的人。

開始之前

準備工具
Node 22+、Chrome／Edge／Chromium，以及可建立網站的 agent；尋找圖片需網路。
使用成本
不需要額外 API key；仍會使用 agent 額度。
交付內容
實際前端網站、響應式版面與檢查截圖
先留意
生圖用的品牌板與介面圖工作流程，已移至 imagegen-skills。
