像素與遊戲 · 9 項 Skill 合集

從能玩的瀏覽器遊戲，做到完整美術與操作回饋

讓 AI 按順序補齊遊戲玩法、模型材質、光影、介面與瀏覽器檢查，也能選擇全程使用本機素材。

它怎麼幫忙可以這樣開口開始之前作者與來源

遊戲原型能動起來之後，常常還缺材質、燈光、操作手感與完整介面。這套九項技能以一個總導演入口串起各階段，讓 AI 先完成可玩的循環，再逐步補足美術與驗證資料。

它怎麼幫忙

先確定玩法、鏡頭尺度和美術方向，再做一小段能操作的代表場景。美術流程先處理模型輪廓與材質，接著是燈光和特效；介面則檢查文字、手機觸控與安全區。最後用真實操作、瀏覽器截圖、畫布檢查與效能資料確認成果。

可以這樣開口

這是一個可依需求修改的委託範例。

做一個低多邊形海島收集小遊戲：玩家駕小船收集漂浮瓶，避開礁石，完成後可重玩。先把一座島和船的造型、材質、海面與手機操作做完整，再擴展其他島嶼；使用程式模型與本機素材，不使用外部生成服務。

適合什麼工作

適合獨立遊戲開發者、互動設計師與想把 Three.js 原型補成可分享作品的小團隊。需要願意看實際操作和畫面，不能只靠評分表判定美術品質。

開始之前

準備工具
需要能修改與執行專案的 Codex 或 Claude Code、Node.js/npm、Python，以及可跑 WebGL 的瀏覽器；內附 Vite、TypeScript、Three.js 起步專案和 Playwright 檢查材料。外部生成另需供應商帳號與金鑰。
使用成本
技能程式與文件為 MIT；核心玩法、程式模型和檢查不要求付費生成 API，但 AI 助手與電腦運算有成本。選用 Tripo 模型、Gemini 圖片或 ElevenLabs 聲音時，各服務另計費並適用自身條款。
交付內容
可操作的 Three.js 網頁遊戲、模型與材質、HUD／手機控制、建置與瀏覽器驗證資料
