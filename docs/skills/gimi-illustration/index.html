文章寫好了，卻不知道哪一段值得配圖？Gimi 會先讀正文、挑插入位置，再安排每張圖要說的意思、構圖和閱讀順序，讓配圖跟著內容走。

它怎麼幫忙

目前提供怪誕手繪、暖調繪本、產品方案三種風格，可指定比例、張數、圖內標題，也可選擇不用角色。若要用自己的角色，先提供正面參考圖、確認角色方案與風格校準圖，再把兩者一起當作後續圖片參考，幫助系列畫面保持一致。

可以這樣開口

這是一個可依需求修改的委託範例。

替這篇「專案改需求如何失控」文章做三張直版配圖，採產品方案風格，不放角色。依序說明修改混亂、找回交付主線、整理成可分享成果。先列插入位置與每張圖的意思，再交付圖片與 shot-config.md。

適合什麼工作

適合中文文章作者、內容編輯、UX 與產品設計師，以及需要方法論或工作流程配圖的人。
