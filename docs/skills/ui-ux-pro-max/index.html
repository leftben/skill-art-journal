最近的觀察

2026-11-03：設計搜尋新增由右至左介面的相容等級。可用 --rtl 查詢，或以 --rtl=full 只看相對安全的選項；partial 仍要逐項檢查圖示、輪播、動作路徑與圖表，caveats 代表設計本身帶有閱讀方向假設。另補 Nuxt UI 4.12 指引；AutoClaw 驗證基準修正不是新美術功能。 2026-11-06：風格資料新增 Apple Native Experience，重點是系統字體、隨明暗模式調整的語意顏色、平台導覽、安全區與可及性控制。例如做手機、平板與桌機共用的設定頁，可依平台安排清單、側欄和彈出面板；不要求用玻璃模糊效果。這是介面風格與實作指引，並非新增 iOS 編譯器；工具與成本條件沿用原文。 2026-11-08：新增中文、日文、韓文輸入法的 Enter 安全指引，避免按 Enter 選字時把未完成訊息送出；例如作品集的詢問表單或聊天框可依此檢查輸入狀態，仍須用實際作業系統、瀏覽器與輸入法手動驗證。同時修正 Windows 預設編碼造成非英文 HTML 讀取失敗、投影片文字亂碼，統一以 UTF-8 讀寫。這是介面行為與文字相容性改善，沿用既有工具與成本。
