角色已經畫好並分成頭、身體、手腳，接下來可以嘗試讓它呼吸、行走或揮手。這個專案把拆件對位、繪製順序與動畫資料串起來，讓 agent 協助建立 2D 骨架動畫。

它怎麼幫忙

實際 SKILL.md 包含 Python 腳本與流程，會利用特徵比對和模板比對對齊拆件，再建立骨架、slot、繪製順序與關鍵影格。列出的動作有待機、走路、跑步、揮手、跳躍與攻擊；位置不準時可用 offset JSON 或互動編輯器調整。

可以這樣開口

這是一個可依需求修改的委託範例。

用我提供的機器人頭、軀幹與四肢透明 PNG，加上完整組合參考圖，先對齊部件，再做待機呼吸與走路循環。提供瀏覽器預覽與 Spine JSON；右手偏高時先調對位，再檢查動畫。

適合什麼工作

適合已有角色拆件的 2D 遊戲開發者、技術美術，以及想理解 Spine 資料管線的人。商用前需先確認專案授權。

開始之前

準備工具
Python 3.9+、OpenCV、Pillow、NumPy；作者以 Claude 工作流為例，也提供手動管線。已有拆件可略過 Gemini；只有整張圖而要自動拆件時需 Gemini 圖像 API。核心可做 Canvas 預覽；同 repo 的額外 Reskin Studio 才另需 Node 18+、Gemini key 與 SAM-3 HTTP 服務。
使用成本
專案採 PolyForm Noncommercial 1.0.0，非商用依條款使用，商用需另洽作者，未公布價格。agent、Gemini 與運算費另計。若使用 Spine 編輯器保存／輸出或整合官方 Runtime，另依 Spine 官方授權；不能把 repo 當成免費商用授權。
交付內容
Spine 4.2 相容 JSON、atlas、PNG 貼圖、HTML 預覽與對位調整資料
