像素與遊戲 · 10 項 Skill 合集

把同風格遊戲道具，接成動畫與地圖素材

讓 AI 記住素材編號與風格，從一張道具圖整理到角色動畫、地圖圖塊和 Godot 資源。

做遊戲美術常常不是缺一張漂亮圖片，而是缺一組能放在一起、輪廓乾淨、能接進引擎的素材。SpriteCook 的十項技能把生成、修整透明邊緣、動畫、地圖與匯入分成可接續的流程。

它怎麼幫忙

先用相同參考圖或已存風格設定製作素材，再以素材編號接續修改和動畫。多件道具可先做 3×3 或 4×4 圖，再檢查與裁切；指定尺寸的 Pixel Engine 路線則一次做單件。角色動畫先查看起始姿勢；去背修邊可比較保留原圖的透明度門檻。地圖有生成與 dual-grid 使用指引；Godot 路線可把圖集和時間資料整理成 SpriteFrames。

可以這樣開口

這是一個可依需求修改的委託範例。

為我的俯視角小酒館做木桶、箱子、袋子、杯子、瓶子、蠟燭、凳子、水桶和鍋子，共九件道具。統一三分之四視角、暖色色盤與左上光源；先給一張九宮格確認，再切成透明 PNG，逐件檢查輪廓和共用畫布。動畫另選定一件後估價。

適合什麼工作

適合獨立遊戲開發者、小型團隊美術和需要持續延伸同一套素材的人。仍需人工確認像素輪廓、動作、地圖接縫與引擎效果。

開始之前

準備工具
需要支援 Skills 的 AI 助手與已連接的 SpriteCook MCP。生成由線上服務完成，技能文件本身不包含模型。可選 Python/Pillow 做本機透明度比較；匯入 Godot 需 Godot 4.x。README 列 Codex 等相容編輯器，本站未實測。
使用成本
技能文件為 MIT；生成、動畫和部分去背會消耗 SpriteCook 點數，AI 助手費用另計。實際價格與可用模型應以服務當下目錄為準，不把文件內點數當固定報價。利用保留原圖調整 alpha cutoff 的修邊流程不另耗生成點數；不能補回原圖本來沒有的像素。
交付內容
透明 PNG、動畫與可選圖集、地圖素材、UI 元件資料、Godot SpriteFrames 等資源
