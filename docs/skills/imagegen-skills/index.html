品牌與設計 · Skill 合集

先做出設計圖，再決定怎麼實作

網站分區圖、手機畫面、品牌板，還有從設計圖片走向程式的流程。

Imagegen Skills9 GitHub 星資料核對 2026.10.20
它怎麼幫忙可以這樣開口開始之前作者與來源

有時候想先看一張設計圖再開工。Imagegen Skills 把網站、手機介面與品牌板的生圖需求，整理成四條明確的工作路線。

它怎麼幫忙

前三個技能分別做網站分區設計圖、手機畫面與品牌規範板；image-to-code 則先生成圖片，再研究並實作相近的網站。這些技能原本位於 Taste Skill，現在獨立維護。

可以這樣開口

這是一個可依需求修改的委託範例。

替一家獨立書店做品牌方向板，包含標誌方向、字體、配色和包裝應用。先交付設計圖片，等選定後再進行網站實作。

適合什麼工作

適合品牌方向探索、介面概念與想先確認畫面再寫程式的人。

開始之前

準備工具
能生圖的 agent；image-to-code 另需寫程式能力。
使用成本
圖片生成依模型與方案計費。
交付內容

先留意
品牌板上的標誌圖不保證是可編輯 SVG。這個新倉庫目前仍在早期觀察。
