3D 與材質 · Skill 合集

從參考圖製作 3D 模型，再準備遊戲或列印交付

把生成、貼圖、減面與下載接成一條流程，另有獨立的 3D 列印準備技能。

你有一張寶箱參考圖，想把它變成遊戲裡可用的模型。Meshy 官方這組 Skills 告訴 AI 助手如何操作 Meshy CLI：選擇生成路線、等待同一筆任務、取得模型與預覽，再接續貼圖、減面或格式轉換。它是服務操作指南，生成品質仍取決於模型、參考圖與人工檢查。

它怎麼幫忙

先說明用途是遊戲素材、角色、渲染還是實體列印，設定格式、面數或尺寸與預算。使用生成技能製作或接續既有模型；列印技能則區分本機縮放、雲端分析／修復與多色輸出。每個階段保留任務編號，最後下載需要的檔案並查看可用的預覽。

可以這樣開口

這是一個可依需求修改的委託範例。

把自己畫的木製寶箱設計圖做成帶貼圖 GLB，存到遊戲素材資料夾；看過預覽後，再要求一份 1,500 面的低細節版本。若改做 150 mm 擺件，則走列印流程，確認尺寸、薄壁與支撐，交付切片軟體檔案。這是本站需求範例，未呼叫服務實作。

適合什麼工作

適合已有 Meshy 付費方案、希望讓 AI 助手整理 3D 製作步驟的獨立遊戲開發者、3D 創作者與模型列印玩家。

開始之前

準備工具
Node.js 22.12+、Meshy CLI 0.8.6 以上的 0.8 系列，以及能執行 CLI 的 AI 助手；雲端工作需網路與帳號登入。列印交接可用 Bambu Studio、OrcaSlicer、PrusaSlicer 或 Cura。
使用成本
技能文字採 MIT；雲端生成需 Meshy Pro 或以上付費方案，並消耗 Meshy 點數，實際費用依所選生成與後製階段。既有 OBJ 的本機縮放、放正與開啟切片檔不需帳號或點數；AI 助手與硬體成本另計。不要把帳號餘額當成報價。
交付內容
依流程下載 GLB、FBX、OBJ 等數位資產，或 STL／3MF 列印檔，另附可用的預覽與任務資訊；不必下載所有格式。
先留意
2026-11-17 首次收錄，非今日發布；專案建立於 2026-03-17，本次觀察 111 星，屬小型官方候選。README 寫「三個」技能，但目前樹狀目錄與技能表實際只有生成、列印兩個，本文依檔案核實。預覽圖不能證明拓撲或可列印性；修復會改幾何並丟失貼圖，須依用途再檢查。未安裝、執行候選或呼叫付費服務。

最近的觀察

2026-11-18：0.9.7 在 3D 列印的參考圖路線加入明確確認步驟：助手先展示參考圖，等你核准才生成模型；選擇路線不等於接受圖片。例如先確認擺件的耳朵與底座輪廓，才花點數建模。這是付費生成前的流程修正，並非新增建模模型。Node 22.12+、Meshy CLI 0.8.5+ 的 0.8 系列及 Pro 以上方案需求不變，生成仍消耗點數；本機既有 OBJ 處理另計，本站未呼叫服務。 2026-11-19：0.9.8 加入 GLB／glTF 的本機互動檢視銜接：meshy view 可開啟模型旋轉縮放；Cursor 插件另附在聊天旁開啟的規則，單獨安裝 Skill 不附此規則。例如交付擺件後，直接轉到背面檢查。CLI 最低提高為 0.8.6（0.8 系列），Node 22.12+；既有模型本機檢視免費，新的雲端生成仍需方案與點數。不是新增生成模型，本站未執行。
