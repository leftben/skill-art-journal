像素與遊戲 · 單一 Skill

從一隻水豚，做出走路動畫

讓 AI 直接安排像素、檢視動作，再交付 GIF 與遊戲用精靈圖。

Pixel Art Studio88 GitHub 星資料核對 2026.10.20
它怎麼幫忙可以這樣開口開始之前作者與來源

像素圖的重點，是每一格色塊都有理由。Pixel Art Studio 讓 AI 用 Python 和 Pillow 直接畫像素，再看自己的預覽、找問題、修改程式。

它怎麼幫忙

除了從零繪製，它也能整理既有圖片的像素格線、透明邊緣與配色。角色動畫會以逐格圖像組成；輸出精靈圖與 JSON，便於接進遊戲流程。

原作者範例

可以這樣開口

這是一個可依需求修改的委託範例。

畫一隻 32×32、戴綠色圍巾的水豚，做四方向走路動畫。每個方向四格，所有動作共用同一套調色盤。

適合什麼工作

適合獨立遊戲、小型角色動畫與想反覆修改像素素材的人。作者示範包含水豚、史萊姆和角色動作。

開始之前

準備工具
Python、Pillow，以及可執行程式並檢視圖片的 agent。README 主要以 Claude Code 為例，安裝路徑需配合環境調整。
使用成本
直接繪製不需生圖 API；若採混合路線使用外部生圖，另依提供者計費。
交付內容
PNG、動畫 GIF、sprite sheet＋JSON
先留意
目前屬小眾候選。本站沒有實測跨 agent 相容性，也沒有以此技能重做作者的動畫。
