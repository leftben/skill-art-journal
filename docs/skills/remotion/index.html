如果影片需要大量字卡、圖表與可重複修改的版型，程式化製作很有幫助。Remotion 的官方 Skills 指導 agent 建立、預覽與輸出 React 影片。

它怎麼幫忙

技能包含建立影片、標記與排版、字幕、互動時間軸、地圖、預覽與渲染。最近的更新加強了鏡頭、字幕和音效該如何分組，讓編輯時更容易一起移動或裁切。

最近的觀察

2026-10-27：4.0.539 的技能文件補齊色階、調色曲線及 Studio 操作。例如替展覽短片提亮中間調，再只調整紅色通道，保持透明區域；圖形編輯器可顯示直方圖並拖曳曲線點。指引明確說這些引擎功能從 4.0.537 已可使用，這次是教學補強，不能說今天才新增調色器。色階數值與曲線強度可在 Studio 設關鍵影格，曲線控制點動畫則需程式處理。React／Remotion 與渲染環境仍需準備，商業授權另依官方條件。 2026-11-10：4.0.542 新增影片去背與前景分層指引。先把影片處理成底片和透明 WebM 前景，再在兩層之間插入可修改文字，或替換、模糊背景。例如替人物訪談做「大標題從人物背後出現」的片頭。人物使用 MODNet；一般主體的 ben2-base 仍屬實驗性，需相容 GPU、較多顯示記憶體與 fp16 支援。Node 路線需 Remotion、Transformers、Mediabunny 等套件，先確認硬體支援再處理一次，不能每格重跑模型。去背不會補出人物後方被遮住的背景；頭髮邊緣與光暈要預覽檢查，音訊只能播放一份。沿用既有 Remotion 授權與 AI 助手成本，硬體運算也需時間；本站只核實指引，未執行模型。 2026-11-12：4.0.543 把「新影片預設可在 Studio 修改」寫成明確製作原則：字卡、圖層與時間要能分開編輯；由外部資料或逐格計算產生、不能直接編輯的部分要先說明。例如同一支展覽短片換三組標題，保留可拖曳字卡，再用 JSON 參數逐版輸出。渲染指引新增命令列參數與伺服器批次範例，並補上授權金鑰、測試渲染標記和實際影格檔名的處理方式；既有可編輯功能並非今天才推出。適合需要反覆改版的影片製作者與開發者；仍需 React、Node 與 Remotion，AI 助手、渲染環境和商業授權另計。本站核對文件，未執行渲染。
