Stitch Skills 的重點是讓 agent 會使用 Google Stitch，並把設計與建置步驟接起來。它依工作分成設計、建置及輔助工具幾組。

它怎麼幫忙

使用前必須先設定 Stitch MCP 與需要的認證。有些技能彼此有相依關係，挑選安裝時要連同所需的技能一起準備。

可以這樣開口

這是一個可依需求修改的委託範例。

用 Stitch 為工作室預約服務探索手機畫面，先整理視覺系統，再依選定的方向做主要流程與可重複使用元件。

適合什麼工作

適合已使用 Stitch，想把介面探索與後續建置銜接的人。

開始之前

準備工具
設定完成的 Stitch MCP、相關認證，以及相容的 agent。
