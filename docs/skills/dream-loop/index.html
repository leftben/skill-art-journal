3D 與材質 · 單一 Skill

先看理想畫面，再反覆做近它

把生圖、實作與視覺評比串成循環，適合場景、遊戲與視覺原型。

Dream Loop1,720 GitHub 星資料核對 2026.10.20
它怎麼幫忙可以這樣開口開始之前作者與來源

有些視覺需求很難用一句「再漂亮一點」說明。Dream Loop 先生成想達到的目標畫面，接著實作，再讓另一個 AI 對照目前畫面與目標，指出差距。

它怎麼幫忙

這個循環會反覆建置、截圖與修改；需要時也重新生成更好的目標。若想製作自訂 3D 模型，作者建議搭配 Blender 與腳本或 MCP。

可以這樣開口

這是一個可依需求修改的委託範例。

做一個等距視角的雨夜小場景。先生成目標圖，再在瀏覽器實作角色、反光地面與燈光，每輪都對照目標修正。

適合什麼工作

適合視覺原型、互動場景與可接受多輪實驗的創作者。

開始之前

準備工具
生圖能力、視覺輸入；分工 agent 非必需但作者強烈建議。自訂 3D 才需要 Blender。
使用成本
多輪生圖與 agent 使用都會消耗額度。

先留意
