用程式做路線、拆解圖與卡通解說短片

從簡短文字或資料開始，完成線條動畫、3D 路線、手機拆解圖與帶配音字幕的解說短片。

Claude Animation Skills695 GitHub 星收錄 2026.11.08資料核對 2026.11.13
它怎麼幫忙可以這樣開口開始之前作者與來源

這套技能把幾種常用直式短片整理成可改的程式模板。簡單的數字折線與路線圖可從規格資料開始；較長的卡通解說則需要一起寫腳本、安排鏡頭、配音與逐字字幕。

它怎麼幫忙

先選六種形式之一：3D 卡通解說、火柴人解說、黑白線條、3D 路線、手機拆解或折線圖。其中四種較短的圖形模板透過 JSON 規格調整文字、顏色與數值，再渲染影片和安全區接觸表；兩種解說引擎需修改鏡頭程式，配合錄音或本機語音，再檢查靜態畫面與完整影片。

三步驟看懂這個技能

可以這樣開口

這是一個可依需求修改的委託範例。

替工作室做一段直式到店路線介紹：使用 3D 路線模板，填入工作室名稱、距離與預估時間，再修改路徑轉折與街區標籤，確認手機上終點卡片不被遮住。這是示意城市，若要精確導覽仍需另外校對真實地理位置。

適合什麼工作

適合短影音創作者、教學設計師與能配合修改程式的設計工作者。簡單圖形比較快；完整卡通解說需一段製作時間，也需要查證旁白內容。

開始之前

準備工具
作者列 macOS 或 Linux、Claude Code、Node.js 18+、Python 3.9+ 與 ffmpeg。安裝會準備 Three.js、GSAP、Playwright 與 HyperFrames；配音與逐字對時需另外下載約 1 GB 模型。3D 需要可用 WebGL，軟體渲染較慢。Windows 與 Codex 路線未由本站驗證。
使用成本
技能程式與文件為 MIT，字型另有 SIL Open Font License。可用本機 Kokoro 或自備錄音，不必購買語音 API；AI 助手、下載空間與渲染時間仍有成本。選用 ElevenLabs 才另計服務費，外部工具與模型適用各自條款。
交付內容
直式 MP4、圖形規格 JSON、動畫程式、靜態預覽及帶安全區的接觸表
