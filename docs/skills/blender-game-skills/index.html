3D 與材質 · Skill 合集

沿著概念圖，做出遊戲 3D 資產

從大形、拓樸、UV、綁定到匯出，每個階段都回頭核對參考圖。

Blender Game Skills160 GitHub 星收錄 2026.10.20資料核對 2026.10.27
它怎麼幫忙可以這樣開口開始之前作者與來源

概念圖變成 3D 資產，中間有很多需要判斷的步驟。這個合集目前以 blender-image-to-3d 為主，指導 AI 在 Blender 裡依參考圖逐步建模。

它怎麼幫忙

它把工作切成 brief、校準、粗模、形體、拓樸、UV 與烘焙、綁定、動畫、匯出及驗收。每個階段要用渲染與可量測的證據確認，而非只憑視窗裡看起來還行。

可以這樣開口

這是一個可依需求修改的委託範例。

依這張正側面機器人設定圖，在 Blender 建立遊戲用模型。先核對剪影與比例，確認後再做 UV、材質、簡單綁定和 GLB 匯出。

適合什麼工作

適合遊戲美術、概念設計師與願意分階段審查 3D 資產的人。

開始之前

準備工具
Blender 4.2+、可執行腳本的 agent，Python／Pillow 檢查；MCP 為可選項。
使用成本
Blender 本身可免費使用；agent 用量另計。
交付內容
Blender 工作成果、GLB／FBX 等遊戲資產
先留意
是參考導向的建模流程，不是按一下就精準重建的神經模型。
